# 番茄鐘（Pomodoro）
## 使用者故事（User Story）
本節用於描述使用者在實際使用番茄鐘時的核心需求與使用動機。

1. 作為使用者，我希望可以開始、暫停、重置、放棄番茄鐘，以便我能依照工作節奏專心工作與休息。

2. 作為使用者，我希望能設定專注時間與休息時間長度，以便番茄鐘符合我個人的工作習慣。

3. 作為使用者，我希望在時間結束時收到提示（聲音或視覺），以便我不用一直盯著畫面。

4. 作為使用者，我希望系統能自動在專注與休息間切換，以便我不中斷地完成一輪番茄流程。

5. 作為使用者，我希望看到一段時間內完成的番茄鐘統計圖表，以便我能檢視自己的專注狀況。

6. 作為使用者，我希望能自訂主題顏色，以便提升使用時的舒適度與專注感。

## 內容清單（Content Inventory）
盤點各頁面實際呈現的資訊內容與介面元素，作為後續 UI Flow 與實作階段的對照依據。
- **計時頁（Timer）**
    - 倒數時間顯示（分鐘：秒）
    - 當前模式狀態顯示（專注 / 休息）
    - 開始按鈕
    - 暫停按鈕
    - 重置按鈕
    - 專注時間設定欄位
    - 休息時間設定欄位
    - 循環次數設定欄位
    - 當前循環次數顯示
    - 視覺提示（模式切換時的狀態變化）
    - 聲音提示（時間結束提示）
    
- **分析頁（Insight）**
    - 完成的番茄鐘次數
    - 專注總時間
    - 連續專注天數
    - 統計區間資訊（例如近一段時間，如一週）
    - 番茄鐘完成次數圖表
    - 專注時間統計圖表
    - 圖表對應說明或標示
    
- **主題設定頁（Theme）**
    - 主題顏色選擇介面
    - 主題即時預覽效果
    - 套用主題後的畫面回饋
    - 偏好設定儲存狀態提示
